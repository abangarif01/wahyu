# Undangan Pernikahan — Situs Statis

File ini berisi situs statis untuk undangan pernikahan `Arif & Laila`.

Cara pakai:

1. Buka `site/index.html` di browser (double-click atau `File → Open`).
2. Ganti gambar hero di `site/assets/placeholder.svg` dengan gambar anime Anda, atau edit `src` pada tag `<img>` di `index.html` ke URL gambar eksternal.
3. Isi detail tanggal/waktu/tempat langsung di file `index.html` (elemen dengan id `date`, `time`, `place`).
4. Untuk menyimpan undangan sebagai PDF: buka `Print` di browser lalu pilih "Save as PDF".

Catatan lisensi: Pastikan gambar anime yang Anda gunakan tidak melanggar hak cipta.
